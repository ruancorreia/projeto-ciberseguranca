Analise de Seguranca Cibernetica

Projeto G2 sobre ataques digitais no Brasil, com dashboard interativo em Streamlit, analise em notebook e visualizacoes com Plotly.

Sobre o projeto

A proposta investiga incidentes ciberneticos entre 2015 e 2024, avaliando tipos de ataque, setores atingidos, regioes criticas, vulnerabilidades, impacto financeiro e tempo de recuperacao.

Indicadores e analises

KPIs Total de incidentes, ataque predominante, setor mais afetado, impacto financeiro, tempo medio e regiao critica.
Visualizacoes Serie temporal, barras, heatmap mensal, dispersao, ranking de vulnerabilidades e tabela dinamica.
Filtros Ano, mes, regiao, estado, setor, tipo de ataque e nivel de criticidade.

Como executar

  • Instale as dependencias com pip install -r requirements.txt.
  • Abra o dashboard com streamlit run app.py.
  • Use o notebook para revisar a analise exploratoria.
